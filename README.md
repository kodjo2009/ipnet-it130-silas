Le projet présente une page de contact html qui contient plusieurs elements à savoir:
 Un formulaire complet avec tous les champs.
 Des labels associés à chaque champ.
 La validation native ( required , minlength , pattern ).
 Un tableau « Mes disponibilités ».
 Un tableau « Mes compétences ».
 Une vidéo intégrée.
 Un fichier audio intégré.
 Des commentaires dans le code.
 Un code propre et indenté.
